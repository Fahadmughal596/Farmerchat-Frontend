FarmerChat Google Login + Payment Module Setup Guide

1) Google Sign-In
- Flutter app already has Google button and google_sign_in package.
- Replace this placeholder in lib/utility/app_constants.dart:
  PASTE_YOUR_WEB_CLIENT_ID_HERE.apps.googleusercontent.com
- Use the Web Application OAuth Client ID from Google Cloud Console.
- The same client ID must be configured on Django backend as GOOGLE_CLIENT_ID.
- Android OAuth client also needs package name + SHA-1/SHA-256 from your build machine.

2) Payment Module
- Payment screen added at lib/views/payment_plans_screen.dart.
- This is a demo/sandbox payment flow for FYP presentation.
- It stores premium status locally using flutter_secure_storage.
- No real money is processed.
- In production, connect this screen with JazzCash, EasyPaisa, Stripe, or bank payment APIs.

3) IoT Dummy Data Removed
- Demo IoT fallback has been removed.
- If ESP32 sensors are not connected, app shows IoT sensors are not connected yet.

4) Build Commands
flutter pub get
flutter build apk --release

APK output:
build\app\outputs\flutter-apk\app-release.apk
